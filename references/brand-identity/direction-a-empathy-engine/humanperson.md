# Humanperson

## Behavior observed
Beige/canvas ground with a visible grid; elements placed organically, like a working desk. Hand-drawn crayon/pencil marks function as UI: frame-by-frame animated preloader glyph (draws itself stroke by stroke with a counter), cursor marks, menu glyphs. Each project page opens with a handwritten pencil/crayon title. Purposeful, restrained animation — "elegant playfulness."

## Why it's a Direction reference
The interface principle for Direction A: hand-drawn as system, not decoration. The hand-lettered project titles express one-of-one, made-for-you empathy typographically. The beige workspace ground makes process ambient — the site feels like a creative team mid-work. Makes the studio feel like a brand clients want to join (LA studio behind Coachella set design — naive marks over world-class substance).

## Likely technique (hypothesis)
Frame-by-frame hand-drawn sprite sequences (canvas or Lottie from scanned frames) for animated marks; SVG for static marks; standard SPA underneath. Heavy canvas — site loads slowly cold.
